# Hardware Inventory Management System

A full-stack web application to manage hardware assets such as laptops, routers, and switches.

## Project Description

This application allows a department to manage hardware inventory efficiently using CRUD operations.

## Technologies Used

- ASP.NET Core Web API
- Angular
- SQL Server
- Entity Framework Core
- GitHub
- Render (Backend Hosting)
- Netlify (Frontend Hosting)

## Features

- Add new hardware assets
- View all assets
- Update asset details
- Delete assets
- Responsive UI
- REST API integration

## Project Structure

hardware-inventory-management
│
├── HardwareInventoryAPI
└── hardware-inventory-ui
